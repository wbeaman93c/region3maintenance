Region 3 maintenance portal — NO LOGIN. Deploy repository to Railway as Node.js service. No PostgreSQL or environment variables required to start. IMPORTANT: JSON records are stored in data.json; Railway ephemeral filesystem means records can disappear on redeploy/restart. For production configure DATA_FILE to a Railway mounted persistent volume path, such as /data/region3.json, and mount volume at /data. Without authentication anyone with the public URL can edit records; restrict access before entering real operational information. Run npm install && npm start locally.
